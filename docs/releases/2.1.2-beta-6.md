## SwiftBar 2.1.2 beta 6

This beta updates the updater framework and fixes crashes, plugin streaming, menu rendering, and Terminal actions.

### Security

- Updated Sparkle from 2.4.1 to 2.10.1, addressing published updater vulnerabilities. #595

### Fixes

- Protected plugin output against concurrent reads and writes, kept URL parameters tied to their refresh, and prevented older runs from replacing newer success with a stale error. Late output from stopped streams can no longer replace a restarted plugin's menu. #583 #585
- Reclaimed streaming invocation slots when a stopped script ignores termination, while allowing cooperative scripts time to clean up. Refreshes can start even when all available slots were occupied by stopped streams.
- Queued URL and file events received during startup until plugins are ready, preventing cold-start `swiftbar://` crashes. Batched refresh URLs are all handled. #596
- Handled empty and invalid SF Symbol palettes without crashing. Scale-only configurations such as `{"scale":"small"}` now work without a rendering mode or colors. #597 #599
- Restored visible images beside multiline dropdown titles and customary menu sizing for plain SF Symbols on macOS 26 and later. Tall images retain their full size while text lines stay together; native title text, explicit dimensions, and configured symbol colors remain supported. #598 #599
- Preserved full multiline images with positive `valign`, including titles with leading or trailing empty lines. #598
- Cleared false stale warnings immediately after wake, including when plugin output is unchanged. #600
- Prevented long `terminal=true` actions from being truncated in Terminal. Long commands use a private temporary file that is removed when the command starts. If macOS denies tab creation or the new tab does not appear, the action opens a new Terminal window instead. #578
- Parsed 24-bit ANSI foreground and background colors correctly. #588 #589
- Selected matching light/dark image and SF Symbol variants. #587 #590
- Applied `length=` to rendered characters and retained readable full-title tooltips. #591 #592
- Added stable accessibility identifiers so menu managers can recognize plugins across title changes and relaunches. #593
- Opened the plugin folder correctly in configured third-party file viewers. #586
- Fixed Shortcuts enable, disable, and reload actions for streaming plugins, and prevented notification actions from racing plugin refreshes.

### Compatibility

Plugins that reversed light/dark image pairs to compensate for the previous behavior should restore the documented light-first order. Plugins that increased `length=` to account for invisible escape sequences may now display more text and can lower the limit.

### Please retest

- Images on macOS 26 and 27: intrinsic sizes, multiline rows, hover, alternate items, and large graph images. #530 #556 #572 #598
- Streaming plugins: frequent updates, repeated refresh URLs, stdin actions, and sleep/wake. #583
- Cold-start refresh URLs, empty palettes, and post-wake warnings. #596 #597 #600
- Long Terminal actions, Shortcuts enable/disable/reload, and saved plugin placement in menu managers.
