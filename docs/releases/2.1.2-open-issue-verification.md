## Validation and limitations

- Full ARM64 and final Rosetta suites each passed 357 tests / 372 executions, no failures, skips, or runtime warnings.
- The first Rosetta full run timed out waiting for an existing streaming operation to drain after restart/termination. Five isolated suite repetitions passed all 20 executions; the final full Rosetta run also passed. No timeout/assertion was weakened, no streaming product code changed, and the failed result is retained. The cause remains unresolved.
- Follow-up: a new deterministic regression failed on the baseline when a stream ignored SIGTERM and held its invocation slot indefinitely. Stopping now closes stdin, requests normal termination, and escalates after one second only against that exact old invocation. New tests verify slot reclamation, refresh on a single-slot queue, replacement survival, and cooperative cleanup. All seven lifecycle methods pass. This establishes a related lifecycle defect; it does not prove the cause of the earlier intermittent Rosetta failure.
- The first graph test incorrectly expected 500×300 *points*. Inspection of the actual PNG's resolution metadata established 375×225 points; the corrected test verifies both the 500×300 source pixels and full intrinsic drawing. That failed run is retained as a test-assumption failure.
- A method-name filter initially selected zero tests; it is not counted as validation. Subsequent full suites include and pass the graph test.
- Independent review caught missing main-actor isolation around `NSAppleScript` compilation. Corrected; the final `codex-review --full-access --mode local` helper reported no accepted/actionable findings. Its focused tests passed. The later build-number-only delta was manually checked.
- CUA's native pipe became unavailable during this pass. The native Terminal proof came from an interactive product-test harness, not another clicked-menu pass. The temporary harness is retained as evidence and excluded from the default suite to avoid opening Terminal on every test run.
- The native image smoke attempt could not write the screenshot, then the old detector force-unwrapped the absent image and crashed. The recipe now rejects missing capture output, clears stale captures, and cleans up on every exit. The detector returns a readable error for missing/invalid input. Isolated command fixtures verify stale/missing capture rejection, cleanup, 52-pixel rejection, and 54-pixel success. These synthetic fixtures do not establish native image dimensions; the exact 54×54 assertion remains unchanged.
- Sparkle rejects this unsigned candidate until trusted signing is present. Upstream 2.10.1 still accepts the existing HTTPS/Apple-code-signing configuration for properly signed bundles. Actual updater validation must use the maintainer-signed artifact.
- Physical Intel and macOS 26 were not available. Rosetta validates the x86_64 slice, not physical Intel hardware.
