## New bug fixes and evidence

Stopped streaming scripts could ignore SIGTERM forever and occupy invocation slots. A new baseline regression reproduced this deterministically. Stop now closes stdin, allows cooperative cleanup, and escalates after one second against that exact old invocation. Tests cover ignored termination, single-slot queue refresh, replacement survival, cooperative cleanup, stopped queued launches, stale output, stdin, and Shortcuts lifecycle calls.

The #598 audit found a missed positive-`valign` case: native AppKit allocated only 91 points of content height to a 100-point image when the title ended with an empty paragraph. The correction measures common line baselines and consistently materializes empty-paragraph metrics. Native attributed text, intrinsic images, and compact line spacing remain intact. The expanded pixel test includes full text retention and uses native menu width; `NSAttributedString.size` alone underestimates continuation indentation even when native AppKit sizes it correctly.

The #600 integration test now posts actual workspace sleep/wake notification names off-main through the production registration on an isolated notification center. It verifies stop/restart, recorded wake time, and immediate warning removal with unchanged output. It does not physically sleep the desktop.

Validation:

- Full ARM64 and Rosetta: 361 methods / 400 executions each, no failures or skips. The final build-number-only correction was checked in the rebuilt/extracted artifact; product code is unchanged from these test runs.
- Thread Sanitizer: 11 lifecycle/notification methods passed with no sanitizer findings.
- Independent actual-source layout probes: 498 cases passed, covering fonts, offsets, empty paragraphs, intrinsic sizes, inline symbols, and flipped/unflipped drawing.
- `codex-review --full-access --mode local`: clean, no accepted/actionable findings. The later build-number and documentation delta was manually checked.
- Baseline failures, final results, matrix sources, and review output: `build-release/release-handoff/evidence/remaining-bugs`. Earlier evidence stays in the superseded worktrees.

## Maintainer release steps

Run from the current worktree after confirming #604 is merged and the intended source is checked out:

```sh
just verify-artifact
just sign
just package
SWIFTBAR_NOTARY_PROFILE='<your existing profile>' just notarize
just staple
just smoke-test
```

`just sign` handles unsigned builds using checked-in production entitlements when necessary and strips `get-task-allow`. The agent has not run signing/notarization commands for this candidate.

Verify the final downloadable archive:

```sh
release_verify_dir=$(mktemp -d)
ditto -x -k SwiftBar.v2.1.2.b627.zip "$release_verify_dir"
codesign --verify --deep --strict "$release_verify_dir/SwiftBar.app"
xcrun stapler validate "$release_verify_dir/SwiftBar.app"
spctl -a -vv "$release_verify_dir/SwiftBar.app"
shasum -a 256 SwiftBar.v2.1.2.b627.zip
```
